# 桌宠：安装与使用

> 面向使用者。桌宠是**可选功能**，不装不影响其它功能；装了之后由引擎里的桥插件驱动，
> 跟着 AI 的工作状态做动作、冒气泡。
>
> 本页只讲「怎么开起来、要什么东西、有什么做不到」。
> 实现原理见 [PET_ARCHITECTURE.md](PET_ARCHITECTURE.md)，功能与后续计划见 [PET_ROADMAP.md](PET_ROADMAP.md)。

## 1. 它是什么

- 一个 `TYPE_APPLICATION_OVERLAY` 悬浮窗 + 前台服务，画在**所有应用之上**，不是无障碍浮层。
- 原生侧只做「身体」：窗口、手势、动画播放、气泡。**它自己不知道 AI 在干什么**。
- 状态来自 dsh 生态里的桥插件 `@xiaopb/dsh-pet-bridge`：插件监听引擎的回合与工具调用，
  往本机回环地址 `127.0.0.1:7779` 发五字段事件，原生侧据此选动画、拼气泡。
- **安装包不含桌宠素材**，也不含桥插件。两边都要用户自己装。

## 2. 开启前必须齐备的三件事

三者缺一不可，**没有任何跳过入口**（2026-10-27 起为硬门禁）：

| 条件 | 怎么满足 | 缺了会怎样 |
|---|---|---|
| 悬浮窗权限 `SYSTEM_ALERT_WINDOW` | 设置 → 扩展 → 桌面宠物 → 点「悬浮窗权限」跳系统页手动授予 | 开关弹出引导窗；服务不启动 |
| 桥插件 `@xiaopb/dsh-pet-bridge` **≥ 0.3.1** 且已启用 | 插件中心搜 `dsh-pet-bridge`，或 `dsh plugin add`；装完**重启引擎** | 开关弹出引导窗；即使服务在跑也会「已暂停：桥插件未就绪」，不画角色 |
| 动画包（至少一个） | 设置页「下载资源包」在线装，或「导入动画包（zip）」本地装 | 开关弹出引导窗；没有素材可画 |

为什么卡 0.3.1 这么死：`/bubble` 从协议 v2 起强制 `X-DSH-Pet-Token`，缺 token 一律 **403**；
npm 上那个无 scope 的 `dsh-pet-bridge@0.1.0` 既没有 token（403），POST 时也不带 `Content-Length`
（Node 走 chunked，原生侧按定长读 body），必然回 **400**。装上也是「看起来连上了但什么都不动」，
所以 App 直接拦在门外，不让你对着静默失败排查。

> 低于 0.3.1 属于「已安装但不兼容」，和「没装」在设置页是两种提示。

## 3. 安装流程

首次安装按顺序走完 6 步，全程约 3–5 分钟（不含下载包的时间）。

1. **正常启动引擎**。桌宠依附于引擎的插件目录 `profiles/web`，引擎没跑起来就没有 `profiles/web`，
   设置页会显示「引擎未运行」。
2. **装桥插件**（二选一）：
   - npm：`dsh plugin add @xiaopb/dsh-pet-bridge`；
   - GitHub：`dsh plugin add github:XiaoPb/dsh-pet-bridge`；
   - 或 App 内插件中心搜 `dsh-pet-bridge`，选名为 `@xiaopb/dsh-pet-bridge` 的条目。
3. **重启引擎**。bundle 插件不会热加载，装完不重启 = 插件在磁盘上但没进 `dsh.profile.bundles`。
4. **授予悬浮窗权限**。设置 → 扩展 → 桌面宠物 → 「悬浮窗权限」→ 系统页打开开关，返回。
5. **装动画包**：
   - 在线：「下载资源包」→ 选 300p / 480p → 等下载与校验（分卷包会逐卷校验 sha256）；
   - 本地：「导入动画包（zip）」→ 选文件。**只收标准 zip**，rar / 7z / tar.gz 请先解压重打包
     （支持范围见 [ARCHIVE_FORMATS.md](../ARCHIVE_FORMATS.md)）；
     加密压缩包、改名成 `.webp` 的 PNG、路径穿越条目都会被拒，并给出具体原因。
6. **打开「开启桌宠」**。通知栏出现常驻通知即启动成功；点通知里的「收起来」停止。

> 不需要手工改 `profiles/web/package.json`，也不需要桌面版的 symlink 安装法。
> 插件中心走的是官方 `dsh plugin --profile web add`，与其它社区插件同一条路径。

**装完之后想确认状态**：设置页开关下方那行状态字会显示「已连接」/「等待桥插件事件」/「已暂停：桥插件未就绪」；
「已连接」表示端口已收到过插件请求。

## 4. 自制动画包（进阶）

官方包不够用、或者想换成自己的角色时，可以自己打一个包。**一个 zip = 一份 `pet-config.json`
+ 一个 `webp/` 目录（+ 可选 `fonts/`）**，不需要签名，也不需要走 CI。

### 4.1 压缩包结构

```
my-pet.zip
├── pet-config.json          # 必需：业务配置（见 4.2）
├── webp/                    # 必需：动画，目录名必须正好是 webp
│   ├── a001.webp            # 文件名（去扩展名）= slug
│   ├── a002.webp
│   └── ...
├── fonts/                   # 可选：气泡字体，兼容旧名 font/
│   └── my-font.ttf
├── LICENSE                  # 可选，但不会装进 App（见下表）
└── NOTICE.md
```

| 规则 | 说明 |
|---|---|
| zip 格式 | **标准 zip**（deflate / store 均可）。rar、7z、tar.gz、加密 zip 一律拒收；分卷只用于在线下载，本地导入要单个完整 zip |
| `pet-config.json` | 必须存在，**可以放在任意层级**（取扫描到的第一个）；建议放根目录 |
| `webp/` 目录 | 必须存在，且动画的**直接父目录名必须正好是 `webp`**。`webp/a001.webp` ✅、`assets/webp/a001.webp` ✅、根目录下 `a001.webp` ❌ |
| slug 命名 | 文件名去掉 `.webp` 就是 slug（`a001.webp` → `a001`），JSON 里所有引用都写这个 slug。**区分大小写**，建议全小写 |
| 字体 | `fonts/*.ttf`、`fonts/*.otf`（或 `font/`）；文件名要和 JSON 的 `font` 字段一致 |
| 其它文件 | 安装器**只解出** `pet-config.json`、`webp/*.webp`、`fonts/*`，`LICENSE`、`NOTICE.md`、`memes/`、`pic/` 等不会进 App 存储（许可文件请随 zip 一起分发） |
| 打包残留 | `__MACOSX/`、`._*`、`.DS_Store` 会被忽略，不算坏包 |
| 路径安全 | 不许绝对路径、盘符、`..`；命中直接整包拒收 |

### 4.2 pet-config.json

可直接改用的完整示例（除 `animations.idle` / `animations.clicks` 必须非空外，其余字段都能删）：

```json
{
  "pets": [
    {
      "id": "my-pet",
      "name": "我的桌宠",
      "size": 150,
      "corner": "top-right",
      "marginX": 24,
      "marginY": 100
    }
  ],
  "names": { "a001": "待机", "a002": "思考", "a003": "点一下" },
  "durations": { "a001": 10041, "a002": 8200 },
  "animations": {
    "idle": ["a001"],
    "turn": ["a002"],
    "drag": ["a002"],
    "clicks": ["a003"],
    "moves": {
      "default": { "minDist": 60, "maxDist": 240, "leadSec": 2.0, "tailSec": 2.0, "margin": 20 },
      "actions": [{ "name": "a002", "minDist": 80, "maxDist": 300 }]
    },
    "categories": [
      { "id": "小动作", "weight": 20, "actions": ["a003"], "noMirror": false }
    ],
    "events": {
      "workStatus": ["a002", "a002", "a002", "a002", "a001", "a002"]
    }
  },
  "animationWeights": { "idle": 10, "turn": 5, "move": 5 },
  "font": "my-font.ttf"
}
```

**顶层字段**

| 字段 | 必需 | 说明 |
|---|---|---|
| `pets` | 是 | 数组，**只读第一个元素**；一个包一个角色 |
| `names` | 否 | `slug → 中文/显示名`。长按菜单、`workStatus` 里写段名时靠它解析 |
| `durations` | 否 | `slug → 段时长(ms)`。缺省 10041，读取后夹在 **500–30000ms** |
| `animations` | 是 | 见下 |
| `animationWeights` | 否 | `idle` / `turn` / `move` 的随机权重，缺省 10 / 5 / 5；分类权重另算 |
| `font` | 否 | 字体文件名（相对 `fonts/`），如 `my-font.ttf` |
| `physics`、`pack` | — | **当前版本不读**，写了也不生效（物理常量固定在代码里） |

**`pets[0]`**

| 字段 | 缺省 | 实际作用 |
|---|---|---|
| `id` | `imported` | **生效**：安装目录名。为 `main` 或空时回退 `imported`；同名已存在会追加 `-2`、`-3` |
| `name` | `Pet` | **生效**：设置页「已安装的包」列表里的显示名 |
| `size` | 150 | 只解析、**不生效**：实际尺寸取设置页的「桌宠尺寸」档位（80–1024dp） |
| `corner` | `top-right` | **不读**：仅保留以兼容桌面版配置；首次位置由系统给默认值 |
| `marginX` / `marginY` | 24 / 100 | **不读**：同上 |

**`animations`**

| 字段 | 必需 | 结构 |
|---|---|---|
| `idle` | **是** | `["slug", ...]`，待机循环；**至少要有一段实际存在的 webp** |
| `clicks` | **是** | `["slug", ...]`，单击回应；同样至少要有一段存在 |
| `turn` | 否 | 转向动画，播完自动翻转朝向 |
| `drag` | 否 | 拖动时循环 |
| `moves` | 否 | `{ "default": {...}, "actions": [{ "name": "slug", ...覆盖 }] }`；`minDist`/`maxDist` 单位 px，`leadSec`/`tailSec` 是动画首尾原地不动的秒数 |
| `categories` | 否 | `[{ "id": "分类名", "weight": 20, "actions": ["slug"], "noMirror": false }]`，`noMirror=true` 的分类在角色朝右时不参与随机 |
| `events.workStatus` | 否 | 6 个槽位，顺序固定：**思考 / 工作 / 整理 / 等待 / 成功（终态）/ 出错（终态）**。每槽可写单个 slug（`"a055"`）、段名（`"工作状态-思考冒泡"`）或多候选数组（`["a055","a056"]`）；缺的槽位用内置兜底 |

> 引用了不存在的 slug 不会导致拒绝安装（只有 `idle` / `clicks` 全缺才拒），但那段永远播不出来。
> 导入前建议自查一遍：JSON 里出现的每个 slug，`webp/` 下都有同名文件。

### 4.3 支持的动画文件类型

| 项 | 支持情况 |
|---|---|
| 容器 | **只接受 WebP**（文件头 `RIFF....WEBP`）。GIF、APNG、PNG、JPG、MP4、webm 即使改名成 `.webp` 也会被拒（"后缀是 .webp，但不是有效的 WebP"） |
| 动画 | 需要**动画 WebP**（`VP8X` + `ANMF` 帧块）。静态单帧 WebP 能装进去，但只会定住不动 |
| 透明 | 需要 alpha 通道（`yuva420p` / 带 alpha 的 VP8L）；否则窗口会是一块实心矩形 |
| 帧率 | 播放端按 **41ms（约 24fps）** 泵帧，与素材帧率对齐最好；帧间隔差异大会看起来忽快忽慢 |
| 解码 | 按包分辨率决定内存：300p 单帧约 0.73MB、480p 约 1.6MB、640p 约 2.9MB；不确定就出 300p |
| 时长 | 每段建议 0.5–30s：`durations` 低于 500ms 或高于 30s 会被夹住；一次性动作按 `durations` 推进，写错会截断 |
| 画布 | 建议 16:9 整幅、角色居中（官方 300p 为 300×168、480p 为 480×270）；App 会自动量出角色矩形，只按角色那块开窗 |
| 帧标志 | 建议 `blend=0`（NO_BLEND）。用 libwebp 默认参数转出来的 `blend=1` 会累积残影，播久了身后拖黑雾——存量包可用 `scripts/probes/fix_webp_blend.py <包目录> --apply` 就地修 |

### 4.4 导入前自检

1. `webp/` 下至少有 `idle` 与 `clicks` 各一段真实存在的动画；
2. JSON 里每个 slug 都能在 `webp/` 找到同名文件（大小写一致）；
3. 单文件 ≤ 50MB、总解压 ≤ 600MB、条目 ≤ 2000、`pet-config.json` ≤ 1MB；
4. 磁盘剩余 ≥ 解压量 × 1.2 + 20MB；
5. 不是加密 zip，没有绝对路径 / `..`；
6. 需要透明就确认素材带 alpha；担心残影就跑一遍 blend 修复脚本。

导入失败时设置页会给出具体原因（错误码已本地化），旧包不受影响。

## 5. 需要哪些资源

| 项 | 要求 | 说明 |
|---|---|---|
| 动画包体积 | 300p ≈ **78MB**、480p ≈ **275MB** | 若发布方分卷，逐卷与整包各校验一次 sha256 |
| 磁盘余量 | ≥ 解压后体积 × 1.2 + 20MB | 安装器先算空间，不够直接拒（不留半成品） |
| 单包上限 | 2000 个条目 / 单文件 50MB / 总解压 600MB / `pet-config.json` ≤ 1MB | 超限即拒，旧包不受影响 |
| 内存 | 解码边长上限 1280px；`memoryClass < 192MB` 的机型降到 720px | 实际占用由**包分辨率**决定，不是屏幕密度：300p 单帧约 0.73MB，640p 约 2.9MB |
| 播放缓存 | 12–48MB（堆上限的 1/16） | 按字节记账，包越大能常驻的段数越少 |
| 系统版本 | Android 8.0（API 26）及以上 | API 28+ 用 `AnimatedImageDrawable`，26–27 用 `Movie` |
| 权限 | 悬浮窗（手动）+ 前台服务通知 | Android 13+ 可在系统里关掉通知：服务仍在跑，但通知栏不再显示状态与「收起来」 |
| 端口 | 本机 `127.0.0.1:7779` | 只绑回环，不占局域网；被别的桌宠工具占用时桌宠能显示但不接收事件 |
| 网络 | 仅在线下载包时需要 | 装完之后完全离线可用 |

## 6. 限制与已知约束

| # | 限制 | 影响 / 原因 |
|---|---|---|
| L1 | 无包 / 无插件 / 无权限 → **不能开启** | 硬门禁，没有「仍然开启」的旁路 |
| L2 | 窗口是**矩形** | 角色轮廓以外的透明角仍算窗口区域，可能挡住下面的按钮。overlay 输入模型限制，除非用私有 API 否则无法按轮廓裁 |
| L3 | 素材被放大约 5 倍上屏 | 300p 包角色在画布里约 120px 宽，窗口常有 600px+。已改成双线性过滤，边缘柔和但**仍无细节可还原**；想更锐只能换更高分辨率包或调小尺寸 |
| L4 | 不注册开机自启 | 打开 App 时按偏好恢复；重启手机后需要进一次 App |
| L5 | 不保证 100% 常驻 | 厂商省电策略（小米、荣耀等）可能杀后台，需手动允许后台活动 |
| L6 | 端口 `7779` 单占 | 与 cc-pet 等其它桌宠工具冲突时只显示、不响应；停掉占用者再重开 |
| L7 | 引擎退出后最多 30s 才回待机 | 服务每 30s 检查一次，避免引擎被杀后永远停在「工作」状态 |
| L8 | 一个包一个角色 | 只用 `pets[0]`；同时装多个包是为了切换分辨率 / 风格，不是同屏多宠 |
| L9 | 素材非商用 | 上游动画素材「允许开源使用、禁止商用」（non-commercial），不随 APK 分发，导入的是用户自己的文件 |
| L10 | 只接受 zip | 其它压缩格式、加密包、损坏 WebP 在导入阶段就被拒 |

## 7. 日常使用

**手势**

| 操作 | 效果 |
|---|---|
| 单击 | Q 弹 + 随机点击回应（a077–a081）+ 短音效（可在设置关） |
| 长按 | 动作菜单：待机 / 点击回应 / 动作分类 / 回位 / 翻转 / 设置 / 收起 |
| 拖动 | 跟手移动；松手在左右边缘 28dp 内自动吸附贴边 |
| 快速甩出 | 抛物线 + 撞边反弹 + 地面摩擦，落地有挤压 |

**自动行为**

- **横向漫游**：闲置时约 26dp/s 散步，走到边界掉头，走 2.5–6s、停 4–11s；
  拖拽 / 甩抛 / 菜单 / 一次性动作 / 引擎回合期间都会让路。
- **贴边躲藏**：贴边后静置 12s 再往外挪半个身位，只露半边；碰一下立即探出。
- **碎碎念**：内置 320 句、11 个情境分类（开机问候 / 单击 / 连点 / 被甩 / 贴边 /
  早中晚时段 / 久置 / 随机 / 工作陪聊）。全部台词共用 20s 冷却。
  台词可在「音效与碎碎念 → 台词库」里按分类改，支持导出 / 导入 JSON、单类或全部恢复内置。
- **工作陪伴**：引擎思考 → 冒思考泡；读文件 / 搜索 → 探索；改文件 / 跑命令 → 忙碌；
  一步完成 → 短确认；整轮结束 → 庆祝 2s 回待机；出错 → 垂头 2.5s。

**设置项**（设置 → 扩展 → 桌面宠物）

悬浮窗权限 · 桥插件状态与重启引擎 · 动画包（当前包 / 已装列表 / 切换 / 删除 / 导入 / 下载 / 下载源）·
桌宠尺寸（记忆档位，超大自动缩到屏内）· 测试气泡 · 单击音效 · 台词库。

## 8. 卸载与空间回收

- **停止**：通知栏「收起来」，或设置页关掉开关。两者都会清掉 `pet_enabled` 偏好，不再自动恢复。
- **删包**：设置页「已安装的包 → 删除」，只删该包，其它包与偏好不动；删的是当前包会自动切到别的包或回无包状态。
- **重复导入**：同内容再导一次会生成 `xxx-2` 副本（不覆盖），确认不需要后手动删。
- **自动清理**：导入失败 / 进程被杀留下的 `.tmp-*`、`.old-*` 半成品下次导入无条件清；
  超过 1 小时未改动的残留由后台巡检清；下载缓存里与本次无关、超 7 天的残件每次下载时清。
- **完全清除**：卸载 App 会删掉 `filesDir/pet/`（含所有包）；桥插件留在引擎 profile 里，需要用 `dsh plugin remove` 单独卸。

## 10. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 设置页显示「需 0.3.1+」，开关打不开 | 装的是旧版（多半是 npm 上游 `dsh-pet-bridge@0.1.0`） | 换 `@xiaopb/dsh-pet-bridge@0.3.1+`，重启引擎 |
| 开关是开的，却看不到宠物；通知写「已暂停：桥插件未就绪」 | 桥插件没装 / 没启用 / 版本过低，被服务层门禁拦下 | 点提示行去插件中心装好 0.3.1+，重启引擎后重开 |
| 通知「已连接」但从不弹气泡 | 插件装了但没进 `dsh.profile.bundles`，引擎没加载 | 设置页点「重启引擎」；仍不行则重装插件 |
| 带 token 仍返回 `400` | 插件未带 `Content-Length`（0.1.0 的 chunked 编码） | 升级到 0.3.1+ |
| 返回 `403` | token 缺失或不匹配：插件旧版，或引擎没重启导致 token 未注入 | 升级插件 + 重启引擎 |
| 状态显示「已安装，请重启引擎」 | 插件装了但引擎还是旧进程 | 重启引擎 |
| 端口 `7779` 被占用 | 其它桌宠工具（如 cc-pet）在跑 | 停掉占用者后重新开启 |
| 装完包、开了开关，角色还是不显示 | 包校验失败被拒（当时应弹出错误）；或当前包被手动删了 | 看一眼设置页「动画包」是否显示已安装，必要时重装 |
| 播放某段后画面越来越脏、身后拖黑雾 | 素材帧标志 blend=1 导致帧间叠加累积 | 换官方包；自建包见 [PET_ARCHITECTURE.md](PET_ARCHITECTURE.md) 的调试一节 |
| 播放中卡住不动 | 解码停摆，看门狗会在 2s 后记录并尝试自愈（最多 2 次） | 偶发可忽略；频繁出现请带上 `log.tag.DshPetView=DEBUG` 日志反馈 |

排查用的协议细节：`GET http://127.0.0.1:7779/ping` 返回
`{"ok":true,"service":"pet-overlay","protocol":2}`，`protocol: 2` 表示带 token 门控的新版。
