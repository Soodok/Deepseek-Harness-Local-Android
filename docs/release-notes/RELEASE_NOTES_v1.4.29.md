## 数据恢复：现在可以导入了（#31）

之前只有「导出数据」，换手机后备份带不回来。现在多了「导入数据」：

- **合并式恢复**：只写入目标位置不存在的文件，**已有的绝不覆盖**——备份之后
  新产生的对话不会因为恢复而消失；
- 同名文件跳过并计数，恢复完会告诉你「恢复了多少、保留了多少」；
- 工作区注册表按**并集**合并，所以恢复出来的对话会真的出现在会话列表里
  （不是「已恢复 N 个、重启后一个都没有」）；
- **安全**：zip 条目做路径穿越检查（`..`、绝对路径、盘符、NUL 全部拒绝），
  且只接受 `sessions/` `workspaces/` 与工作区注册表——备份包里本不该有
  `profiles/`（凭据）和 `engine/`，出现即跳过，防止构造的包写到敏感位置；
- 条目数、单文件、解压总量都有上限，超限直接失败而不是写一半。

恢复完成后可直接点「立即重启引擎」让新数据进入列表。
