# DSH Mobile v1.4.28

> 修复一个会让应用卡死重启的问题：在插件中心频繁点击时，主线程被反复阻塞。

## 插件中心频繁点击导致卡退（#58）

反馈现象是：打开设置 → 社区插件，正常用一会儿（约 30 秒）后卡住，然后回到
「引擎准备中」的启动界面。

**原因不是插件中心太重，是主线程被反复拖住**：

1. 分类筛选条有 24 个按钮，绘制选中态时每个按钮都要读一次 1.7MB 的插件目录
   —— 打开一次插件中心就是 24 次全量解析；
2. 点分类会重新读目录、重建 3540 条列表，频繁点击时这些任务堆积。

主线程被卡住超过阈值，系统判定应用无响应并结束进程，引擎随之重建——你看到的就是
「卡退 + 重启引擎界面」。

**现在**：

- 插件目录与分类列表在内存里缓存，一个进程只解析一次；
- 分类切换改为纯内存过滤（目录已经在内存里），不重新读文件、不发起后台任务；
- 绘制按钮选中态不再碰文件。

**效果**：插件中心的打开、搜索、切换分类都变成内存操作，重复点击不再累积。

## 其它
