# DSH Mobile v1.4.27

> 两条移动端体验修复，都来自社区实机反馈（@Masspedro）。

## 软键盘回车 = 换行（#53）

以前回车是「发送」、Shift+Enter 才是换行——可手机软键盘没有 Shift 键，写多行
消息实际做不到，一按回车就发出去了。

现在触屏设备上：

- **输入框有内容时，回车换行**，发送交给界面上的发送按钮；
- **输入框为空时，回车仍然是发送**（保留了「敲完直接回车发出去」的顺手）；
- 外接键盘、桌面模式不受影响，仍是原来的桌面快捷键；
- 输入法组字中（选候选词）不会被误判成换行。

## 附件直接选照片（#54）

以前发图片要先走「文件」流程，进文件管理器再翻到图库目录。现在页面只要图片时
（`accept="image/*"`），附件按钮直接打开**系统照片选择器**：

- 缩略图网格、最近照片一眼可见；
- 支持相册切换与多选；
- **不需要任何存储权限**（系统选择器只把你选中的照片交给应用）；
- 「文件」入口照旧，文档和压缩包仍走文件选择器。

低版本 Android 上没有系统照片选择器的设备会回退到图库选择，路径不变。

## 引擎启动阶段文案补齐
