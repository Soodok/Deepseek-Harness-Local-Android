# DSH Mobile v1.6.0 — 记忆系统（AI 干过的活，下次不用重新学）

> 这一版加的不是新功能，是**让 AI 越用越熟**：它做过的无障碍任务会被录下来、剪干净、存成记忆，
> 下次同类任务直接按记忆重放，不再从头读屏、从头规划。

## 1. 记忆系统做了什么

```
录制（每个动作一次读屏）
  → 剪枝（六条规则：去掉观测、重试、无效点击、重复滚动、绕路）
  → 存储（按应用分文件，pending 转正）
  → 检索（向量 + 屏幕结构比对 + 三档阈值）
  → 重放（每步重读屏校验锚点，对不上就拒绝）
```

**最要紧的一条设计**：重放时每一步都要重新读屏、确认目标元素还在。
锚点对不上就**停**，绝不按记录下来的坐标盲点 —— 坐标盲点正是这套东西要消灭的失败类型。

## 2. 你能看到的变化

- 设置页多了「记忆」入口：能看到 AI 记住了哪些任务、命中几次、失败几次。
- 每条记忆可以**标注**（给它一句人话名字）、**禁用**、**删除**、**试跑**。
- 两个开关：`录制`（关掉就完全不记录）与 `自动学习`（关掉后任务结束不自动入库）。
- 任务干完后记忆先以「待确认」入库，**同一场景再成功一次**才转正 —— 一次成功可能只是运气。

## 3. 实测数据（模拟器 Android 11，不是估算）

| 项 | 结果 |
| --- | --- |
| 录制开销 | **+40 ms/动作**（相对 1.7 秒/步是 2.4%） |
| 关掉录制 | **零开销**（不读屏不写盘） |
| 剪枝 | 9 步轨迹剪成 4 步（去掉误点、重复滚动、绕路） |
| 重放 vs 手打（同一 2 步任务） | 0.99 秒 vs 1.55 秒 |
| 词面改写检索 | top-1 9/10 |
| 跨应用隔离 | 双向 0 误命中 |
| 存储上限 | 记忆 500 条 / 轨迹 200 个，合计 ≤2 MB |

## 4. 安全边界（这部分比功能更重要）

- **分档闸门**：只有「意图像 + 当前屏幕也像」才自动执行；只像一半就拒绝，交给模型正常规划。
  实测：意图完全一致但屏幕没有证据时，得分 0.60 → 低档 → 拒绝执行。
- **保护页**、**换应用**、**用户叫停**，任一发生立刻停。
- 输入框内容**永远不进记忆**（那是隐私），只记「点了哪里」。
- 记忆连续失败两次会自动降为「可疑」，不再自动命中。

## 5. 已知限制（这一版没解决）

- 语义检索的本地嵌入模型需要单独下载（15 MB），没下载时退化成字符匹配，语义改写命中率会明显下降。
- 平板双栏、德语/泰语长文案下的面板排版只做了静态推断，没逐语言截图验证。
- 以「启动某个应用」开头的记忆，如果当前不在那个应用里，会被拒绝重放（安全优先）。

## 6. 升级说明

直接覆盖安装即可。旧版（v1.x）的场景记忆会在首次运行时自动迁移到新格式，原文件改名保留可回滚。
