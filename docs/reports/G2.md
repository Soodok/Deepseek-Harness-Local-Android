## 3. 两个实现取舍（Lead 已确认）

1. **规则 3 收窄**：`unchanged` + 锚点非空 + 后面存在任何改变屏幕的动作 → 删；**跳过 scroll**。
   理由：滚动归 scroll-fold；否则折叠出的 scroll_to 继承最后一次 unchanged 会被二次删除，9→4 直接崩成 9→3。
2. **detour 跨度上限 `MAX_DETOUR_GAP = 3`**：真实任务里「回原屏再点下一项」是正当路径，跨度太大删掉就是破坏。

## 4. 断言有效性（定点破坏）

- 把 `scroll-fold` 挪到 `noop-verify` 之后 → 2 红（折叠步被二次删除）
- 去掉 `MAX_DETOUR_GAP` → 1 红（误删跨度为 4 的正当回退）
- `replayable` 改成恒 true → 1 红（保护页仍可入库）
