## 2. 脚本的确定性约定（踩过的坑，别改回去）

| 坑 | 现象 | 现在怎么做 |
| --- | --- | --- |
| 设置页记住滚动位置 | 已在底部时 `frameChanged` 永远等不到变化，scroll 步判超时 | 录制前 `am force-stop com.android.settings` |
| 同名意图的历史记忆 | top-1 断言指向旧条目（cos 都是 1） | 意图带 `int(time.time())` 时间戳 |
| 「点搜索框」进保护页不稳 | 有时落到 `.Settings` 而非 intelligence，闸门不响 | 直接 `am start -n com.android.settings.intelligence/.search.SearchActivity` |
| 模拟器没装 llama.cpp | 检索恒为 hash，`tier=high` 永远到不了 | 断言 top-1 + cos，engine≠bge 时 SKIP 并注明 |

## 3. 复跑方式

```bash
cd dsh-android
# 只跑 E2E（前提：包已装、引擎已起、WebView 门已过）
bash scripts/gate-memory.sh e2e          # 门禁 5/5 阶段，失败即 GATE FAIL

# 发版前一条命令跑完：静态 + 构建 + 装机 + E2E
bash scripts/gate-memory.sh release      # ~10 分钟

# 也可以直接跑脚本，退出码 = 失败段数
PYTHONIOENCODING=utf-8 python scripts/e2e-memory.py
```
