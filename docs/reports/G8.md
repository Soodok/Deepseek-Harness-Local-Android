## 3. 真机发现并修掉的一个真缺陷：新页面不跟随 App 内语言

第一版面板整页**英文**，而设置页是葡萄牙语。根因：
- `ThemedActivity.attachBaseContext` 只包了 `ThemeManager.wrap`；
- 语言包装 `LocaleHelper.wrap` 是 `SettingsActivity` **单独**重写的。

新页面只继承 `ThemedActivity` → 没有语言包装 → 退回系统语言（本机系统是英文，App 内设的是葡语）。
修复：两个新 Activity 都加

```kotlin
override fun attachBaseContext(newBase: android.content.Context) {
    super.attachBaseContext(LocaleHelper.wrap(newBase))
}
```

修完面板变成 `Memórias / memórias / acertos neste app / pendentes / Gravar / Aprendizado automático`。
**这类缺陷只在「系统语言 ≠ App 内语言」时才暴露** —— 默认环境（系统与 App 同语言）永远测不出来。

## 4. 顺手补的端点

`POST /memory/v2/config {"autoLearn":bool,"recordEnabled":bool}` —— 之前 `autoLearn` 是只读的
（`@Volatile var` 无赋值点），设置页那个 Switch 只能弹回去，用户会以为坏了。现在 UI 的 Switch 直接打这个端点，
并用回包的真实值回写两个 Switch（不做乐观更新），失败回弹。
