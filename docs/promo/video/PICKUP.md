## 录制通用建议

- **录屏方式**：手机自带录屏（下拉快捷开关 → 屏幕录制），**麦克风静音**，只要画面。
- **分辨率**：1080×2400 竖屏录制即可，进剪映再裁。
- **时长**：比建议时长久 2–3 秒，便于裁切对齐。
- **不要**出现通知弹窗、微信消息、个人聊天内容。
- **不要**露出 API Key、手机号、真实姓名、私人对话。

## 清单

### 1. 插件市场真实安装（建议 8 秒）★ 优先

| 项 | 内容 |
|---|---|
| 对应镜头 | `plugins`（第 4 镜，**16.50–21.00 秒**） |
| 录什么 | 打开「插件中心」→ 搜索一个插件 → 点安装 → 进度条跑完 → 显示已安装 |
| 建议时长 | 8 秒 |
| 画中画位置 | 竖屏：屏幕中下部，占宽 72%，圆角 24px；横屏：右侧 1/3 |
| 注意 | 选**安装快**的插件（≤5 秒），别选要编译原生的 |

### 2. 真实终端跑命令（建议 6 秒）★ 优先

| 项 | 内容 |
|---|---|
| 对应镜头 | `performance`（第 2 镜，**3.00–10.00 秒**，放在该镜后半段） |
| 录什么 | 进「终端」→ 敲 `node -v` → 回车出结果 → 再敲 `python --version` |
| 建议时长 | 6 秒 |
| 画中画位置 | 竖屏：屏幕中部，占宽 78%；横屏：居中偏左，占宽 55% |
| 注意 | 命令要**一眼看懂**，用 `node -v` 这类人人认识的，别用自造脚本 |

### 3. 手表启动（可选，但最有说服力）★★★

| 项 | 内容 |
|---|---|
| 对应镜头 | `performance`（第 2 镜，**3.00–10.00 秒**，与第 2 条二选一或分区） |
| 录什么 | 紫光展锐手表（3GB）点开 DSH Mobile → 等到「Engine ready」出现 |
| 建议时长 | 15 秒（后期加速压缩到 13 秒内） |
| 画中画位置 | 竖屏：右下角小窗，占宽 34%；横屏：左下角 |
| 注意 | **这是全片最有说服力的素材**，别人无法复制。手持拍手表屏幕也行 |

### 4. Web UI 真机操作（建议 7 秒）

## 优先级

只录一条：**第 3 条（手表启动）**。那是别人无法复制的证明。

录两条：加第 1 条（插件安装，最直观）。

录三条：加第 2 条（终端，证明是真环境）。

## 剪映对齐提示

- 占位区**消失的那一帧**就是该贴上去的那一帧。
- 画中画建议 **8–12px 圆角 + 柔和阴影**，与片子深色卡片风格统一。
- 画面偏亮/偏暗用「调节 → 亮度/对比度」微调，别调太狠导致失真。
- 配音音轨在 `voice/narration.wav`（52.000s，-16 LUFS），音乐你自己配，
  **音乐音量压到 -26 dB 左右**才不会盖住人声。
